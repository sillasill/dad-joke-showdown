`main.ts` writes a single dad joke (129 characters) to `/output/entry.txt`:

> Our Wi-Fi went down at dinner, so I told the kids we're finally having a real family connection. Nobody laughed — the router did.

Run with Node.js (`node main.ts`). Standard library only, deterministic, no network.
